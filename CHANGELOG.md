# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-09-27

### Added
- Complete NEXIAL AI master's programme website
- Homepage with hero section, programme overview, research section, faculty showcase, and admissions CTA
- Curriculum page with 6-module learning roadmap
- Fully functional admissions application form with validation
- Responsive navigation with mobile menu
- Smooth animations using Framer Motion
- SEO metadata and Open Graph tags
- Accessibility features (ARIA labels, semantic HTML)
- Security headers configuration
- Vercel deployment configuration
- Complete documentation (README, deployment guides, checklists)

### Fixed
- Page routing and file organization
- Navigation links and internal routing
- Form validation and error handling
- TypeScript compilation errors
- Responsive design issues
- Hydration warnings
- CSS and animation inconsistencies
- Accessibility compliance

### Changed
- Updated branding from NOVA to NEXIAL
- Enhanced metadata and SEO optimization
- Improved form UX with real-time validation
- Optimized performance and bundle size
- Enhanced security headers configuration

### Security
- Enabled strict TypeScript mode
- Added security headers (X-Content-Type-Options, X-Frame-Options, X-XSS-Protection)
- Configured HTTPS (automatic on Vercel)
- No API keys or sensitive data exposed

### Performance
- Optimized images and lazy loading
- Minimized CSS and JavaScript bundles
- Configured caching headers
- Enabled code splitting
- Target Lighthouse score: 95+
